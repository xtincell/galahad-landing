Pourquoi Galahad

Ton serveur, ton fournisseur, tes règles

La plupart des « produits à agents » sont le cloud d'un autre qui détient tes clés, ton code et tes données. Galahad inverse ça.

🔌

Cerveau agnostique

Pointe LLM_BASE_URL vers n'importe quel endpoint OpenAI-compatible — Ollama, OpenAI, OpenRouter, Together, Groq. Change de modèle à chaud avec /brain. Aucun lock-in.

💸

Économe par design

La patrouille de routine coûte zéro token ; les modèles forts seulement à la demande ; Claude seulement pour les pics. Coût quasi nul au repos.

🔒

Garde-fous dans le code

Toute action destructive ou payante est refusée sans un « oui » explicite de l'opérateur dans les 5 dernières minutes. Imposé dans hooks.js, pas par la politesse d'un prompt.

📓

Mémoire fichiers

Cartes markdown + un index injecté au réveil. La continuité survit aux redémarrages ; tout est grep-able. Journaux en JSONL, entièrement auditables.

🛡️

Aucun port entrant

Les agents sortent en long-polling Telegram. Rien à exposer, aucune surface d'attaque entrante à défendre.

⚡

Une commande

Un moteur léger (~500 lignes de Node sans dépendances). ./install.sh — Docker + Compose et c'est en ligne.

Quickstart

En ligne en trois lignes

Un VPS Linux avec Docker, trois bots Telegram (un par agent, via @BotFather), et une clé pour un endpoint LLM OpenAI-compatible.

bash — your VPS
# clone & lance — install.sh demande les tokens, le chat id, l'endpoint LLM
git clone https://github.com/xtincell/galahad.git
cd galahad
./install.sh

# …ou à la main
cp .env.example .env          # remplis tes valeurs
docker compose up -d          # les trois agents
docker compose --profile bridge up -d   # + le bridge Claude optionnel

Puis écris à un bot sur Telegram et envoie /help.

Ce que Galahad n'est pas

L'honnêteté est une feature. Galahad ne promet pas la lune — il fait une chose, bien.

// n'est PAS

  • ✕ un SaaS managé — rien ne tourne dans notre cloud
  • ✕ un studio no-code — c'est du vrai framework à héberger
  • ✕ un AGI ni un « auto-pilote » magique
  • ✕ autonome sans garde-fou — il demande avant de livrer
  • ✕ lié à un fournisseur de LLM unique

// EST

  • ✓ un petit framework lisible (~500 lignes de Node, zéro dépendance)
  • ✓ auto-hébergé sur ton VPS, tu possèdes tout
  • ✓ agnostique : n'importe quel endpoint OpenAI-compatible
  • ✓ sûr par conception : garde-fous imposés dans le code
  • ✓ auditable : journaux JSONL + mémoire markdown
